# Projet Académique - OCR

## Fonctions
Projet machine learning lié à nos études visant à développer un système de reconnaissance optique de caractères (OCR) capable d’extraire du texte manuscrit depuis des images et de le convertir en caractères ASCII.

## Objectif
Dans un premier temps, être capable d’extraire individuellement les mots d’une même phrase.
Puis, être en mesure de retranscrire des phrases complètes.
